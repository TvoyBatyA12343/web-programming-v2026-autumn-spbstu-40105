# Лабораторная работа 5

## Задание

Реализовать пагинацию книг в книжном интернет-магазине.

- Список книг с обложкой, названием, рейтингом, описанием и ценой.
- Компонент пагинации под списком: кнопки «Назад», «Вперёд» и номера страниц.
- Список отображает 9 книг на странице в сетке 3 колонки (3 элемента в строке).
- Пагинация рассчитана на большое количество страниц (до 20+).

## Реализация

Приложение на React + Vite.

### Данные

Массив `BOOKS` содержит 27 книг, сгенерированных на основе базового списка из 9
произведений (повторяются с разными `id`). Это даёт 3 страницы по 9 книг.
`BASE_BOOKS` содержит сами данные: название, автор, рейтинг, описание, цену и
цвет обложки.

### Компоненты

- **`BookCard`** — карточка книги. Помечена `data-testid="book-card"`.
- **`Pagination`** — пагинация. Содержит кнопки `page-previous`, `page-next`,
  набор кнопок `page-number` и текстовый индикатор `page-indicator`.
- **`App`** — корневой компонент. Хранит номер текущей страницы в `useState`,
  вычисляет срез массива книг и передаёт в дочерние компоненты.

### Логика пагинации

- `totalPages = Math.ceil(BOOKS.length / BOOKS_PER_PAGE)` — общее количество
  страниц.
- Текущая страница хранится в `useState`.
- Кнопки «Назад» и «Вперёд» меняют состояние на ±1 и блокируются на границах.
- Кнопки с номерами позволяют перейти сразу на нужную страницу.
- `getPageNumbers` вычисляет, какие номера показывать (до 5 подряд, с
  центрированием вокруг текущей). При большом количестве страниц лишние номера
  заменяются многоточием. Это покрывает требование «страниц может быть 20».

### DOM-контракт

| Элемент            | Селектор                         |
| ------------------ | -------------------------------- |
| Карточка книги     | `[data-testid="book-card"]`      |
| Кнопка «Назад»     | `[data-testid="page-previous"]`  |
| Кнопка «Вперёд»    | `[data-testid="page-next"]`      |
| Номер страницы     | `[data-testid="page-number"]`    |
| Индикатор страницы | `[data-testid="page-indicator"]` |
