# Лабораторная работа 3

## Задание

Вариант 2. Реализуйте функцию rotateArray(arr, steps), которая сдвигает массив
вправо на steps элементов.

## Реализация

Сначала проводится проверка данных на корректность (step - целое). Если массив
пустой, возвращаем его. Шаг нормализуется: `k = ((steps % n) + n) % n`
Возвращается новый массив: сначала последние k элементов, затем первые n - k

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
