# Лабораторная работа 4

## Задание

Вариант: класс `Student` и коллекции студентов.

### 4.1. Класс `Student`

Поля:

- `id` — уникальный идентификатор (число);
- `name` — имя студента (строка);
- `grades` — объект, где ключи — названия предметов, а значения — оценки
  (числа).

Методы:

- `addGrade(subject, grade)` — добавляет или обновляет оценку по предмету;
- `removeGrade(subject)` — удаляет оценку по предмету;
- `getAverageGrade()` — возвращает средний балл по всем предметам;
- геттер `summary` — возвращает строку
  `"Студент [name] (id: [id]) — средний балл: [средний балл]"`.

### 4.2. Функции коллекций

- `groupStudentsByAverageGrade(students)` — группирует студентов по среднему
  баллу; возвращает объект вида `{ "4.50": [Student, ...], ... }`.
- `getUniqueSubjects(students)` — возвращает уникальный список всех предметов,
  встречающихся у студентов.
- `groupStudentsBySubject(students)` — группирует студентов по предметам,
  возвращая `Map` предмет → массив студентов, у которых есть оценка.
- `getTopStudents(students)` — возвращает массив студентов с максимальным
  средним баллом.
- `findStudentsBySubject(students, subject)` — возвращает список студентов,
  сдавших указанный предмет.

### 4.3. Интерфейс

- Список карточек студентов с ID, именем, средним баллом и списком предметов с
  оценками.
- Форма добавления студента (поля `id`, `name`).
- Форма добавления оценки (поля `id`, `subject`, `grade`).
- Форма удаления оценки (поля `id`, `subject`).
- Кнопка удаления студента внутри карточки.
- Все операции добавления и удаления выполняются асинхронно через `Promise` +
  `setTimeout`.
- Список автоматически перерисовывается после каждой операции.
- Текущий список студентов сохраняется в `localStorage` и восстанавливается при
  следующем открытии страницы.

## Реализация

Класс `Student` хранит оценки в объекте `grades`. Метод `addGrade` использует
тот факт, что в JS объект — это словарь: если ключа ещё нет, он добавляется,
если есть — значение перезаписывается. Поэтому один метод решает и добавление, и
обновление. `removeGrade` использует `delete`.

`getAverageGrade` получает массив оценок через `Object.values`, проверяет длину
(при отсутствии оценок возвращает 0, чтобы избежать деления на ноль) и считает
среднее через `reduce`. Геттер `summary` формирует строку по шаблону, средний
балл округляется до двух знаков через `toFixed(2)`.

Функции коллекций используют встроенные средства языка:

- `getUniqueSubjects` — `Set` для автоматического отбрасывания дубликатов;
- `groupStudentsByAverageGrade` — `reduce` со стартовым `{}`;
- `groupStudentsBySubject` — `Map` с методами `has/get/set`;
- `getTopStudents` — `Math.max(...)` для поиска максимума и `filter` для отбора
  всех, у кого средний балл равен максимуму (может быть несколько);
- `findStudentsBySubject` — `filter` и оператор `in` для проверки наличия
  ключа-предмета в `grades`.

Все функции **не мутируют** входной массив — они возвращают либо новый массив,
либо новый объект/`Map`.
